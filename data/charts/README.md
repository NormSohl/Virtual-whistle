# Fingering charts

`pattern`: holes 1-6 from the mouthpiece end. `x` closed, `o` open, `h` half-covered.
`register`: 1 = first (fundamental) register, 2 = second (overblown) register.
`primary`: the standard fingering; `no` rows are common alternates.
Pitches are sounding pitches for a whistle in D (lowest note D5, 587.33 Hz at A4 = 440 Hz).

## d_whistle_standard.csv
Standard D whistle fingerings, first and second octaves, chromatic notes by half-holing.
Source: Woodwind Fingering Guide, tin whistle charts (first and second octave), contributed by Eoin McAuley.
https://www.wfg.woodwind.org/tinwhistle/tw_bas_1.html and tw_bas_2.html.
That guide labels the octaves D4/D5 as written pitch; this file uses sounding pitch (one octave higher).
